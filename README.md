Heart Disease Prediction using Decision Tree and Random Forest
This project uses the Heart Disease dataset to build and evaluate classification models using Decision Tree and Random Forest algorithms. The objective is to predict the presence of heart disease based on clinical features.
Tasks Performed
Train a Decision Tree Classifier

A decision tree is trained and visualized to understand the decision paths.

Analyze Overfitting

Tree depth is varied and accuracy on training vs. testing data is plotted to detect overfitting.

Train a Random Forest Classifier

A Random Forest is trained and its performance is compared with the Decision Tree.

Feature Importances

Feature importances from the Random Forest model are visualized to understand key predictors.

Cross-Validation

Both models are evaluated using 5-fold cross-validation for more reliable performance estimates.
